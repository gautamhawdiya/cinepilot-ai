# CinePilot AI

AI-powered film production assistant.

## Project Structure

- `agents/` - Various AI agents for different aspects of film production
- `tools/` - Utility tools used by the agents
- `api/` - API endpoints
- `frontend/` - Frontend interface
- `docs/` - Documentation
- `tests/` - Test cases
- `prompts/` - Prompt templates

## Setup

1. Install dependencies: `pip install -r requirements.txt`
2. Set up environment variables in `.env`
